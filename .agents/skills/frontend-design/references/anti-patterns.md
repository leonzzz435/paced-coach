# Anti-Patterns

Review these before finalizing a design-heavy change.

## Common failures

- **Card soup**: too many same-weight panels with no dominant focal point
- **Gradient camouflage**: loud gradients or glass effects hiding weak hierarchy
- **Equal emphasis everywhere**: headline, metric, CTA, helper text, and chrome all fighting at once
- **Theme drift**: one page or scene invents a new visual language that does not belong to the rest of the experience
- **Decorative motion**: animations that do not clarify hierarchy, state, or sequence
- **CTA overload**: multiple primary actions competing in the same viewport

## Product UI failures

- marketing-style hero treatment inside task-oriented app flows
- huge display typography where users need dense scanning
- elegant empty states paired with cluttered real-data states
- visual polish added without clarifying success, next action, or status

## Dashboard failures

- picking a chart because it looks sophisticated instead of because it answers the question
- too many series with low contrast or ambiguous labels
- decorative donuts, 3D effects, or micro-card grids replacing a useful trend view
- mixing units, time scales, or baselines without obvious cues

## Marketing failures

- premium-looking shells with no proof, evidence, or credible CTA
- section-to-section randomness with no pacing
- over-designed hero sections followed by weak body sections

## Quick correction heuristic

If a screen or scene feels "busy but vague," reduce simultaneous emphasis before adding more style.
