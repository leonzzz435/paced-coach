# paced.coach v2.2.0

paced.coach is now a complete local-first AI endurance coaching app: describe your goals, training history, availability, and constraints; generate a season roadmap and a day-by-day 28-day execution block; then continue the same plan context in coach chat.

## Highlights

- **No wearable required.** One supported LLM API key plus athlete-declared context is enough for the baseline coaching path.
- **One continuous coaching flow.** Profile, race calendar, season strategy, 28-day plan, calendar, and plan-aware coach chat live in the same app.
- **Provider-free by design.** External training-data OAuth, imports, daily sync, and weekly recaps are not part of v2.2.0.
- **Local-first ownership.** The Next.js app, FastAPI API, Celery/LangGraph workers, PostgreSQL, and Redis run locally through Docker Compose.
- **Safer public baseline.** The release removes hosted auth, payments, private athlete artifacts, and hosted deployment assumptions from the public tree, and adds a pinned secret/history audit.

## Important Boundaries

- The no-login application is intended for a single local owner and binds host-visible services to loopback by default. Do not expose it directly to a public network.
- Coaching output is generated by the LLM provider you configure. It can be incomplete or wrong and requires athlete judgment.
- paced.coach provides training support, not medical diagnosis or treatment. Stop and seek qualified care for concerning symptoms or injuries.
- Athlete data is stored in the local PostgreSQL volume by default. The configured AI provider receives the context required for model calls; optional LangSmith tracing creates an additional intentional network path.
- The coach must not claim recent activity, compliance, load, HRV, sleep, recovery, or readiness trends unless the athlete explicitly provides them.

## Verified Environment

The release candidate was exercised on Ubuntu/Linux under WSL2 with Docker Compose, Pixi, Node.js 24, and OpenAI as the only configured LLM provider. The provider-free flow produced a seven-phase season roadmap, a complete 28-day plan, and a plan-specific coach response, and survived a normal stack restart. Other operating systems remain best-effort until independently verified.
