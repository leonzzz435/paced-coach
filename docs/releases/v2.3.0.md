# v2.3.0 — release draft

Status: unreleased candidate. See [verification](v2.3.0-verification.md).

This release prepares paced.coach as a local-first, provider-free coaching app
and an inspectable agent-engineering reference. Athlete profile, goals, race
calendar and declared constraints remain the input to planning and coach chat.

## Changes

- Opt-in GPT-6 Astra routing for Head Coach and research, with explicit Responses
  API reasoning profiles and unchanged default model selection.
- Updated Python and frontend dependencies to resolve known advisories.
- Excluded local environment files, temporary evidence and database exports from
  Docker build contexts so self-hosted images do not copy local private files.
- Restored public environment examples in source archives and made the release
  content scan include tracked files even when excluded from archives.
- Bound both frontend start commands to loopback by default, matching the
  single-owner application boundary during the documented local setup.
- Prevented a delayed profile load or save from overwriting ongoing edits, and
  blocked saving defaults after a failed initial load. Added browser regressions
  for these states. Development startup preserves the repository's agent guidance.
- Fixed zero-tool memory and presentation profiles rejecting their own structured
  answers. Application tool limits remain enforced and are regression-tested.
- Fixed PostgreSQL JSON encoding when accepting coach proposals and recording
  their usage event. Retry coverage checks that usage is charged only once.
- Isolated public demo navigation and temporary checkmarks from the local app.
  Removed the legacy device-metric report from the provider-free preview.
- Added desktop/mobile browser acceptance, reproducible synthetic capture, current
  screenshots, accessible form names, architecture and contributor documentation.
- Added an Agents API decision record and bounded synthetic model observations.

## Upgrade notes

Use your normal local restart procedure after updating dependencies. No database
schema change is introduced. The checkpoint library patch update retains the
existing declared migration head and checkpoint schema version.

To select Astra, set `AI_MODE=astra` in the root `.env` and restart API and worker.
Inference still uses your OpenAI project and is billed there. Do not copy an API
key into the browser, repository or a public deployment.

Each user runs the full application with their own infrastructure and OpenAI
key. No Vercel, Clerk or Stripe account is required. The local app has no login
and must remain bound to loopback. Publication, exact-commit CI and external
legal review are tracked in the verification document; this draft does not
certify completion of those gates.
