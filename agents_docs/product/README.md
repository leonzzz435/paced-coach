# Product Docs

This folder is intentionally small for the local-first OSS release.

Current product positioning lives in:

- `README.md` for the public setup and user-facing product promise.
- `agents_docs/roadmap/roadmap.md` for durable product direction.
- `agents_docs/roadmap/decision_log.md` for major strategy changes.

Do not add managed-service launch, account-service, payment-processor, or vendor-deployment material here unless the roadmap explicitly reintroduces that product direction.
